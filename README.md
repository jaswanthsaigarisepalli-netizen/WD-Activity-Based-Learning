## 🚀 How to Run the Projects

1. Clone or download this repository.
2. Open the project folder on your computer.
3. Locate the `index.html` file for the website you want to view.
4. Open `index.html` in your web browser.

Alternatively, open the project using Visual Studio Code and run it with the Live Server extension.
